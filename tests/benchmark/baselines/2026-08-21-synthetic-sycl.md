# Phase 2 baseline — synthetic SYCL run — 2026-08-21

This file records the first hardware-backed prompt comparison reported from the target local SYCL environment.

## Configuration

- preprocessing: enabled
- production prompt: `OCR`
- candidate text prompt: `Text Recognition:`
- specialized probes: `Table Recognition:` and `Formula Recognition:`
- corpus: deterministic synthetic corpus generated by `benchmark_prompt_quality.py`
- text samples: clean text, small text, noisy scan, mixed layout

## Text recognition results

| Prompt | Runs | Mean CER | Mean elapsed |
| --- | ---: | ---: | ---: |
| `OCR` | 4 | 0.0000 | 24.63 s |
| `Text Recognition:` | 4 | 0.0000 | 23.51 s |

Per-sample CER was `0.0000` for both prompts on all four text samples.

The apparent timing advantage of `Text Recognition:` is **not treated as evidence of a speed improvement** because the benchmark executed all `OCR` runs first and all `Text Recognition:` runs second. The first `OCR` sample took 27.19 s versus 20.61 s for the corresponding candidate run, so startup/warm-state/order effects can materially bias the simple mean.

## Specialized probes

### Table

`Table Recognition:` returned structurally valid HTML matching all visible cells:

```html
<table border="1"><tr><td>Prodotto</td><td>Q1</td><td>Q2</td><td>Totale</td></tr><tr><td>Alpha</td><td>12</td><td>15</td><td>27</td></tr><tr><td>Beta</td><td>8</td><td>11</td><td>19</td></tr><tr><td>Gamma</td><td>20</td><td>18</td><td>38</td></tr></table>
```

Elapsed time: 18.04 s.

### Formula

`Formula Recognition:` produced LaTeX-like output, but the quadratic formula rendered the `+/-` operator as `+ / -` rather than a proper `\pm`/equivalent expression. Therefore this single synthetic probe is **not sufficient to validate formula mode**.

Elapsed time: 19.69 s.

## Decision

No production prompt change is justified by this run:

- quality is tied on the synthetic text corpus;
- the timing comparison is order-biased;
- specialized task prompts are promising but need broader and task-specific scoring.

The next benchmark iteration must use warm-up, counterbalanced prompt order, repeated rounds, and a path for real-world labelled documents before the roadmap can close the prompt-selection item.
